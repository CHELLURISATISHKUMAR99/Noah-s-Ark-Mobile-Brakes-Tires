# Asset Sources & Attribution

Approved website asset selection. Every file listed here was downloaded from the
provider's own media endpoint and verified by file signature (JPEG `ffd8`, ISO Media / WebM
container). No HTML page was ever saved and renamed as media. No asset was substituted.

- **Originals (untouched downloads):** `assets-original/` — kept outside `public/` so they are never served.
- **Optimized (web delivery):** `public/assets/`
- All files are served locally from this repository. Nothing is hotlinked from an external host.

## Access notes

Both providers block scraping of their HTML pages, but both serve their actual media freely:

- Pexels photo/video **pages** returned HTTP 403 to direct requests; the `images.pexels.com` CDN
  and the official `pexels.com/download/video/<id>/` endpoint both served genuine media normally.
- Unsplash returned an HTTP 401 bot challenge on both its page and its `/download` endpoint.

## Reproducing the optimization

Images were resized with Pillow (LANCZOS) and saved as WebP `quality=82, method=6`.
Widths are capped at 1920 px (desktop) and 900 px (cards); aspect ratio is preserved and
**no image is ever upscaled** — a source narrower than the target is left at its native width.

Video was encoded with a self-contained `ffmpeg-static` binary run from a temporary directory.
No system packages were installed, and no video tooling was added to the project's dependencies.
